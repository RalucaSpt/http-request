# Angular HTTP Requests Project  
Tutorial: Angular - The Complete Guide (2025 Edition) Section 12: Sending HTTP Requests & Handling Responses

---

This project demonstrates how to manage HTTP requests and responses in an Angular application, based on concepts such as:

- **HttpClient** for interacting with APIs.
- Configuring and sending **GET**, **POST**, and **DELETE** requests.
- **Optimistic updating** for improved user experience.
- Managing app-wide error handling with **HTTP interceptors**.
- Transforming response data and reusing HTTP logic via **services**.
